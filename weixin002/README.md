# 我形我衣 · 微信小程序原型

基于 `PRD-我形我衣-v1.0.md` 与 17 张关键设计图（`page_01…page_17`）完成的**小程序高保真交互原型**。

> v2 说明：上一版采用「截图 + 浮层按钮」导致按钮/文字/图形对不齐，本版已全部改为
> **HTML/CSS 原生绘制的小程序界面**——按钮、文字、图形按统一网格与间距严格对齐；
> 主体照片（登录插画、数字人、服装、试穿效果图、对比模特）从原图裁剪保留；
> 全部配色仍取自原图像素采样。

## 打开方式

直接打开 `index.html`（原型预览器）：

- 左侧：17 个屏幕按「首页与登录 / 数字人创建 / 试穿链路 / 我的与隐私」分组，附 PRD 需求编号；
- 右上：切换「设计稿 / iPhone 15 Pro / Android Pixel」三种预览形态；
- 底部：上一屏 / 下一屏 / 自动演示；
- 「PRD 映射」：查看图片 ↔ 屏幕 ↔ PRD 章节的完整对照表。

也可直接打开 **`woxingwoyi-demo.html`**：17 屏合并为一个可交互演示文件（手机画布内切换全部屏幕，含侧栏导航、上一屏/下一屏、自动演示与全部控件交互），无需预览器即可逐屏演示。

如需**可带走、可导出的单文件**，请用 **`我形我衣-单文件演示.html`**：17 屏、样式、脚本与全部图片已全部内嵌（约 12MB），拷到任意电脑/发给任何人都能直接打开，适合作为小程序前端开发的设计手稿。

## 保真原则（按你的要求执行）

  1. **主体照片来自原图**：插画、数字人、服装、试穿效果图、对比模特均从对应原图裁剪，未重新绘制、未删改主体。
  2. **界面为原生绘制**：按钮、Tab、表单、文字、图标全部由 HTML/CSS 按统一网格绘制，按钮与文字天然居中对齐，颜色使用原图采样值。
  3. **小程序而非网页**：17 屏均为独立页面文件，含小程序自定义导航栏、底部四 Tab（发现 / 试衣 / 收藏 / 我的）与安全区适配；预览器仅为审阅工具。

## 可交互内容

- 登录 → 创建向导（性别选择、身高/体重滑块）→ 隐私授权 → 生成进度（进度环动画）→ 3D 数字人 → 选择衣物（模板多选）→ 预览确认（品类单选）→ 试穿进度（自动进入）→ 结果（角度切换、保存、分享）→ 对比视图（选择圆点）；
- 首页搜索框可输入、一键试穿卡片、热门模板与数字人卡片跳转；
- 个人中心 / 试穿记录 / 隐私管理（删除二次确认）/ 反馈页全部列表与 Tab 可跳转；
- 身材参数页：三围步进器、腿长/肤色滑块、缺省估算开关均可用。

## 说明

- 身高体重沿用原图示例值（165cm / 50kg）；三围数值原图过小无法精确识别，按 PRD 示例档案补齐为 88 / 66 / 92cm，可在开发时接入真实表单。
- 底部 Tab 选中态按页面语义校正（首页=发现、试穿=试衣、记录/我的系=我的），修正原稿中不一致的选中项。
- 照片上传页将原稿中重复的两行操作合并为底部单一「生成数字人」主按钮，每张照片卡可独立选择上传。
- 预览器「iPhone / Android」模式复用仓库共享设备外框；「设计稿」模式以 390×769 预览真实页面布局。

## 试穿出图：全身像说明

- 按 PRD FR-16a / FR-17，试穿生成以 3D 数字人**全身渲染**为底图，**默认输出正面全身像**，可选侧面 / 背面；结果页文案已注明。
- 当前 17 张原图中的试穿效果图素材本身为 **3/4 人像构图**（头部到裙摆/膝上），并非头到脚；原型未对原图主体做删改，因此效果图按原图构图展示。
- 如需在原型中展示真正的“头到脚”全身效果图，可：① 提供一张全身试穿效果图素材，直接替换 `assets/img/p07-result.png`、`assets/img/p13-*.png`；② 或授权我用 AI 生成同风格全身示例图（人物与原型不完全一致，仅作示意）。

## 登录插画背景修正

- 原图登录插画的背景在粉→蓝过渡中混有一段米黄（淡黄绿）色带。原型素材 `assets/img/p01-hero.png` 已做像素级修正：仅将该段背景重绘为平滑的粉→蓝渐变，三位插画人物零改动（已逐像素审计）；原始文件 `page_01_login.png.jpeg` 保持原样未动。
