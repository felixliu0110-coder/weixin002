状态机校验。

新增一个独立的事务完成函数，职责明确：

finalizeTryonSuccessAtomically(...)

函数负责：

1. db.startTransaction()
2. transaction.collection("tryon_tasks")
3. transaction.collection("tryon_results")
4. 在事务内重新读取 Task
5. 判断当前 Task 状态
6. 获取真实结果
7. 查询 tryon_results where task_id
8. 更新 Task

事务外绝不进行 AI/Provider 调用。

十、事务实现约束

CloudBase 服务端使用：

const tx = await db.startTransaction();

所有参与原子操作的数据库访问必须使用：

tx.collection(...)

不能在 Transaction 中混用：

db.collection(...)

完成后：

await tx.commit();

异常：

await tx.rollback();

rollback 本身失败不能覆盖原始业务错误。

事务只做数据库读写。

禁止：

事务中调用 AI
事务中调用 Provider
事务中下载图片
事务中执行长耗时网络操作
