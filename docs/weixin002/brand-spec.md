> 本规范由用户提供的 17 张关键设计图逐像素采样生成，作为「我形我衣」小程序的视觉契约。

## 一句话总结

暖米色画布 + 纯白卡片 + 豆沙玫瑰粉单一强调色的轻量时尚工具型小程序界面；圆角胶囊按钮、极简线性图标、大面积留白。

## 字体

- 展示 / 标题：`"PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", system-ui, sans-serif`（Semibold / Medium 字重）
- 正文：同上字体族（Regular 字重，15–17px）
- 等宽 / 数字：`"SF Mono", ui-monospace, Consolas, monospace`（身高体重、百分比、日期）

## 观察到的视觉规则

1. **双主色节奏**：暖米色页面背景与纯白卡片交替；强调色只用豆沙玫瑰粉一系，用于主按钮、选中态、进度与 Tab 高亮。
2. **胶囊几何语言**：主按钮、Tab、品类与角度选项均为全圆角胶囊；卡片圆角 16–26px；3D 页与对比页使用圆形操作钮。
3. **导航结构**：自定义导航栏（返回 + 居中标题 + 搜索）；底部四 Tab：发现 / 试衣 / 收藏 / 我的，选中项为粉色胶囊或粉色图标文字。
4. **表单密度**：创建向导分 3 步，顶部细进度条；身材参数用大卡片 + 滑轨；数值使用等宽数字并带单位（cm / kg）。
5. **进度表达**：生成类页面使用大号环形进度（数字居中）；等待提示统一为「可离开页面，完成后通知你」。
6. **合规痕迹**：试穿结果与记录卡统一带「AI 生成」标签；隐私相关页面在操作前以弹窗/底栏二次确认。
